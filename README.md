# Dam Ey (ដាំអី) - Smart Agriculture & Agro-Dealer Platform

A Khmer-first agricultural mobile and web prototype connecting Cambodian farmers with local agro-dealers, soil testing analysis, fertilizer recommendations, and inventory management.

## 🚀 Live Demo on Vercel
Deploy seamlessly by importing this repository into Vercel (https://vercel.com).
